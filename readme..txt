# Hybrid Multi-Sensor Predictive Maintenance Framework

This project uses:
- Vibration signals
- Acoustic signals
- Electrical/Thermal/Power sensor data

Models Used:
- Random Forest
- CNN-BiLSTM
- Hybrid Ensemble

Features:
- Multi-sensor fusion
- Fault diagnosis
- Predictive maintenance
- Remaining Useful Life estimation

Dataset:
- CWRU Bearing Dataset
- Acoustic WAV files
- CSV sensor data

Results:
- Accuracy: 95.76%
- F1 Score: 95.78%
- ROC AUC: 99.74%
